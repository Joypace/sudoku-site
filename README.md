# Sudoku Let's Try website

Public static files only. No private App source, account credentials, puzzle packs, or player data.

## Homepage preview

Open `index.html` locally to review the homepage. It uses `home.css`, `home.js`
and optimized WebP App screenshots in `home-assets/`; no remote font or build
step is required to view it. Clicking a screenshot opens its full-size view.
The tip illustrations are SVG animations, generated by
`python3 tools/generate_home_tips.py` from the captured App example data in
`tools/home_tip_examples.json`. These are explanatory illustrations, not a
playable puzzle or a live App renderer. Native SVG playback has Pause/Play and
Replay controls, pauses offscreen, and honors reduced motion.

Store download links are omitted until their destination and availability are
confirmed.

## Hosting with Cloudflare Pages

Connect only `Joypace/sudoku-site` to Cloudflare Pages (not Workers).

| Setting | Value |
|---|---|
| Production branch | `main` |
| Framework preset | None |
| Build command | `exit 0` |
| Build output directory | `.` (repository root) |
| Root directory | Leave default |

The `_headers` file gives Apple's extensionless association JSON Content-Type. One small Pages Function handles only the share HTML to preserve the exact Safari banner URL; static JS, Wasm, fonts and all other routes do not invoke it. No secrets are needed. First verify the generated `*.pages.dev` URL, `/app-ads.txt` and the association's delivered Content-Type. The repository CNAME file belongs to the retained GitHub Pages setup; Cloudflare custom domains must be added in the Cloudflare dashboard.

Add `sudoku.joypace.com` in the Pages project's Custom domains **before** changing external DNS. Use the actual `*.pages.dev` hostname Cloudflare assigns; do not guess its name.

| DNS type | Name | Target |
|---|---|---|
| CNAME | sudoku | The assigned Cloudflare Pages hostname |

Replace the existing sudoku CNAME to pi.joypace.com. Leave pi.joypace.com, the blog and other DNS records unchanged. You do not need to transfer the joypace.com domain or change its nameservers for this subdomain setup.

GitHub Pages had one authorized deployment; GitHub Actions are disabled again. Connecting Cloudflare Git integration uses Cloudflare's own build service, not GitHub Actions. It normally deploys future main-branch pushes automatically; use Pages deployment controls if manual publication is desired.

## Public routes

- `/app-ads.txt`: Google AdMob publisher declaration for both platforms.
- `/privacy/`: app privacy policy for individual developer Li Zhang, contact sudoku@joypace.com.
- `/share/?p=…`: serves the existing compiled read-only preview and its local renderer/font resources on this host. There is no Pi redirect. Existing pi.joypace.com links continue working independently.
- `/.well-known/apple-app-site-association`: public Apple association captured from the working share host before cutover. Signed application capabilities still govern native opening. Before DNS cutover, verify this extensionless file is actually served with application/json Content-Type using the supplied Cloudflare header rule. The prior GitHub Pages deployment serves application/octet-stream and is not qualified for native opening. The current host returns 404 for Android assetlinks.json; Android verified HTTPS opening needs separately verified signing-certificate evidence. No certificate is invented here.

The original compiled artifact is unchanged (App source 97bbdffa9f9cbfbe847f78aa777fba0da5424f8b; main.dart.js SHA256 98afcf7050c8129ea7fa02fef36415e8f3e6ccc3949d312da5614b6c9ff77855). Its runtime licences are included. The HTML banner is generated by functions/share/index.js with escaped current URL and no-store caching, replacing nginx SSI. Only /share and /share/ invoke a Function; _routes.json keeps image/JS/Wasm/font requests static. The preview creates no profile/session, exports no gameplay controller and preserves its existing read-only behavior.

Set https://sudoku.joypace.com/ in the public App Store Marketing URL / Google Play developer website field. Once live, verify `/app-ads.txt` directly, then request AdMob's app-ads.txt check. TestFlight-only availability does not substitute for the public store listing.
