Locked Triple: three cells reserve two houses.

Three cells reserve two houses.

The idea

Find three cells whose combined candidates contain exactly three digits. When those cells share a row or column and a box, the three digits occupy those cells in both houses. Remove those digits from the other cells of the line and box.

The cells need not each have all three candidates. Count the complete line and box; every elimination must lie outside the triple and share at least one of those houses. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Locked Triple: example 1

These cells share row 5 and box 5:

  • r5c4 has only 1, 6.
  • r5c5 has only 6, 8.
  • r5c6 has only 1, 8.

Together they contain only 1, 6, 8. Those three digits fill the three cells, reserving them in both complete houses.

Copy the original once for each possible value of the same starting cell:

  1. If r5c4 is 1, the forced placements are r5c6 = 8, r5c5 = 6.
  2. If r5c4 is 6, the forced placements are r5c5 = 8, r5c6 = 1.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 1 from r4c6.
  • Remove 8 from r4c6.
  • Remove 1 from r5c8.
  • Remove 6 from r5c8.
  • Remove 8 from r5c8.
  • Remove 1 from r5c9.
  • Remove 6 from r6c5.
  • Remove 8 from r6c5.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
