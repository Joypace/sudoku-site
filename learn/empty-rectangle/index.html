Empty Rectangle: a box cross and an outside link.

A box cross and an outside link.

The idea

Inside a box, one digit is confined to a row arm and a column arm. An outside strong link connects to one arm. Either link placement rules out the same target using the other arm.

The “empty rectangle” refers to the box positions outside the cross that have no candidate for this digit. It does not mean the whole box is empty. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Empty Rectangle: example 1

In box 1, every 2 candidate is at r1c2, r2c2, r3c1. They lie on row 3 or column 2, with no 2 at their intersection. The outside link is r4c2, r4c7: the only two places for 2 in row 4.

Copy the original once for each possible value of the same starting cell:

  1. If r4c7 is 2, that placement itself rules out the target notes.
  2. If r4c7 is 7, the forced placements are r4c2 = 2, r3c1 = 2.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 2 from r3c7.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
