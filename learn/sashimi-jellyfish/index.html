Sashimi Jellyfish: four lines, a fin, and a simpler pattern underneath.

Four lines, a fin, and a simpler pattern underneath.

The idea

For one digit, four base rows or columns use four crossing cover lines, apart from a fin outside those covers. A target outside the bases, on a cover and seeing the fin, cannot contain the digit. If a target contained it, the fin would be excluded and one cover would be occupied, leaving four base placements in only three remaining covers.

Sashimi means that excluding the fin reveals a simpler structure. Each example identifies a single or a smaller fish that the fin prevents. The copied trials may follow ordinary singles of other digits as well; only their first fill is a guess. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Sashimi Jellyfish: example 1

These are all the places for 6 in the four base rows:

  • Row 2: r2c2, r2c3, r2c5, r2c6.
  • Row 4: r4c2, r4c3.
  • Row 5: r5c4, r5c5.
  • Row 9: r9c2, r9c5.

The covers are columns 2, 3, 4, 5. The fin is r2c6 in box 2, outside the covers.

Without the fin, rows 2, 4, 9 reserve exactly columns 2, 3, 5: a Swordfish. The subset includes the fin’s own row; the fin prevents that reduction while it remains possible.

The remaining base row 5 must then use cover column 4. This is the four-line pattern’s additional placement.

If the fin is 6, it directly excludes every target that sees it. Otherwise the complete four-base reservation still excludes those target notes. The animations explore every value of the same starting cell, then overlay the real trials.

Copy the original once for each possible value of the same starting cell:

  1. If r2c6 is 6, that placement itself rules out the target notes.
  2. If r2c6 is 8, the forced placements are r5c5 = 8, r5c4 = 6, r2c5 = 6, r9c2 = 6, r4c3 = 6.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 6 from r3c4.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.

Sashimi Jellyfish: example 2

These are all the places for 4 in the four base columns:

  • Column 3: r2c3, r6c3, r9c3.
  • Column 5: r6c5, r8c5.
  • Column 7: r2c7, r8c7, r9c7.
  • Column 8: r6c8, r7c8.

The covers are rows 2, 6, 8, 9. The fin is r7c8 in box 9, outside the covers.

Without the fin, its own column has just one place left: r6c8 = 4. That forced single makes the fin-free body degenerate.
