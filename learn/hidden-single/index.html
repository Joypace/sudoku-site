Technique of the day · November 25, 2026

Hidden Single: one place for a digit.

A cell can have several possible digits and still be forced. Find the digit that has only one place left in its row, column or box.

Search a whole unit

Choose a digit missing from a row, column or 3×3 box. Check its empty cells against the given digits. If only one cell can take that digit, put it there.

A Naked Single has only one candidate in a cell. A Hidden Single has only one place for a digit within a unit, even when that cell has several candidates.

r2c1 means row 2, column 1; count from the top left. Boxes are numbered left to right, top to bottom. The highlights guide this explanation. These animations use Chill Mode, where a double tap fills a forced digit. Each play link opens exactly the starting clues shown here; your app’s display settings may differ.

Example 1 of 3

Only r8c5 can hold 1 in row 8

Row 8 has no 1 yet. Every completed Sudoku row contains each digit once, so this row still needs a 1.

Check every other empty cell in row 8 against the starting clues:

  • r8c1 cannot be 1: the given 1 at r5c1 is in the same column.
  • r8c2 cannot be 1: the given 1 at r7c2 is in the same column.
  • r8c4 cannot be 1: the given 1 at r3c4 is in the same column.

That leaves only r8c5. Its candidates are 1, 3, 7, so looking at this cell alone does not settle it. Looking for 1 across the whole row does: r8c5 must be 1.

Fill r8c5 with 1

This is a direct forced placement. Any notes that disappear after the fill are ordinary row, column and box consequences of placing 1.
