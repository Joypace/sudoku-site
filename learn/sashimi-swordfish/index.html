Sashimi Swordfish: three lines, one fin, the same exclusion.

Three lines, one fin, the same exclusion.

The idea

For one digit, three base rows or columns use three crossing cover lines, apart from a fin outside those covers. A target outside the bases, on a cover and seeing the fin, cannot contain that digit. If it did, it would exclude the fin and occupy one cover, leaving three base placements confined to only two other covers.

These examples have one fin and just one body candidate in its base. Without the fin, that body candidate is forced; the fin-free shape is degenerate. The other two bases each have two body candidates. Count every candidate in all three bases, and keep all the derived targets. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Sashimi Swordfish: example 1

These are all the places for 8 in the three base rows:

  • Row 3: r3c3, r3c4.
  • Row 6: r6c4, r6c7.
  • Row 8: r8c2, r8c7.

The covers are columns 2, 4, 7. The fin is r3c3, in box 1, outside the covers.

  • r2c2 lies on cover column 2, outside the base rows and in the fin’s box.

If the fin is 8, it sees and excludes every target. If it is not 8, r3c4 = 8 is forced. The copied trials below follow the forced placements through all three bases; every trial rules out the same target.

Another way to check it: a target containing 8 would rule out the fin and consume one cover. The three disjoint bases would then need three placements in just two remaining covers. That cannot happen.

Copy the original once for each possible value of the same starting cell:

  1. If r3c3 is 7, the forced placements are r3c4 = 8, r6c7 = 8, r8c2 = 8.
  2. If r3c3 is 8, that placement itself rules out the target notes.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 8 from r2c2.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
