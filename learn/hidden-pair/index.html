Hidden Pair: two digits have only two places.

Two cells may contain several notes, while two digits quietly reserve those cells for themselves.

The idea

In one row, column or box, find two digits that can each appear only in the same two cells. Those cells must contain the two digits in some order. Remove every other candidate from those cells. The two digits must each be available in both cells.

Each example starts at Dilemma with zero forced singles. The full-unit native highlight emphasizes both digits in their only two places. Copied boards test both assignments; Chill Mode makes the second forced placement visible. Each play link opens exactly the starting clues shown here; your App’s display settings may differ. r2c1 means row 2, column 1; boxes are numbered left to right, top to bottom.

Example 1 of 3

In row 5, only r5c4 and r5c9 can hold 4 and 7

In row 5, both 4 and 7 have exactly the same two possible cells: r5c4 and r5c9. Both cells still have extra notes, so this is not yet a Naked Pair.

  1. If r5c4 is 4, r5c9 must be 7.
  2. If r5c4 is 7, r5c9 must be 4.

These exhaust both assignments. Those two digits must occupy these two cells, whichever order is right.

Remove the other notes from the pair cells
  • Remove 6 from r5c4.
  • Remove 8 from r5c9.

Keep 4 and 7 in both cells. They now form a Naked Pair.

Compare the same candidate in both trial overlays. A mark occurring in only one trial is not a shared conclusion.
