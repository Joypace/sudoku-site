Claiming: a line reserves a digit in a box.

When a row or column has nowhere else to put a digit, it can reserve that digit inside one box.

The idea

Find every possible place for one missing digit in a row or column. If all those places are inside the same 3×3 box, remove the digit from the rest of that box outside the line. Count every candidate on the entire source line, not just a convenient pair.

Each example starts at Dilemma with zero forced singles. The native highlight shows the full source line and every candidate. Pointing goes from box to line; Claiming goes from line to box. Each play link opens exactly the starting clues shown here; your App’s display settings may differ. r2c1 means row 2, column 1; boxes are numbered left to right, top to bottom.

Example 1 of 3

Row 5 claims 1 inside box 6

The only places for 1 in row 5 are r5c7, r5c9. Every one is inside box 6.

  1. If r5c7 is 1, no other 1 can appear in box 6.
  2. If r5c9 is 1, no other 1 can appear in box 6.

These are all the possible placements on the source row. Whichever is correct, it uses the box’s one 1. The other cells of that box cannot take 1.

Remove candidate 1 from r4c9

These are exactly the 1 candidates inside box 6 but outside row 5. Keep the source line’s original candidates.

Every trial uses a separate copied board. Compare all of their overlays before removing a shared exclusion.
