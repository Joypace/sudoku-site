Finned Swordfish: a three-line fish with a fin.

A three-line fish with a fin.

The idea

Compare a three-line fish’s normal placements with its extra fin candidates. An elimination must be ruled out both by the fin case and by the fish when the fins are absent.

Count all base candidates, including fins, and check every target’s visibility. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Finned Swordfish: example 1

For 7, these are all its candidates in the 3 base columns:

  • Column 1: r5c1, r6c1, r9c1.
  • Column 6: r5c6, r6c6.
  • Column 8: r6c8, r8c8, r9c8.

The normal fish uses rows 5, 6, 9. The extra fin is at r8c8, in box 9.

If the fin holds 7, it directly excludes every target. If it does not, the normal fish reserves those rows. Every target lies on a cover outside the base columns and sees the fin, so both cases exclude it.

Copy the original once for each possible value of the same starting cell:

  1. If r8c8 is 4, the forced placements are r6c8 = 7, r5c6 = 7, r9c1 = 7.
  2. If r8c8 is 7, that placement itself rules out the target notes.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 7 from r9c9.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
