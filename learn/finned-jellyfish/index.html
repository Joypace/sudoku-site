Finned Jellyfish: a four-line fish with a fin.

A four-line fish with a fin.

The idea

A four-line fish may still give an elimination when extra candidates are confined to a fin box. A target must be excluded by every fin placement and by the underlying fish.

This lesson treats the complete fin set, without silently ignoring extra candidates. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Finned Jellyfish: example 1

For 2, these are all its candidates in the 4 base rows:

  • Row 2: r2c1, r2c5, r2c9.
  • Row 3: r3c5, r3c8.
  • Row 8: r8c1, r8c3, r8c5, r8c8, r8c9.
  • Row 9: r9c1, r9c5, r9c9.

The normal fish uses columns 1, 5, 8, 9. The extra fin is at r8c3, in box 7.

If the fin holds 2, it directly excludes every target. If it does not, the normal fish reserves those columns. Every target lies on a cover outside the base rows and sees the fin, so both cases exclude it.

Copy the original once for each possible value of the same starting cell:

  1. If r8c3 is 2, that placement itself rules out the target notes.
  2. If r8c3 is 7, the forced placements are r8c8 = 2, r3c5 = 2, r9c1 = 2, r2c9 = 2.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 2 from r7c1.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
