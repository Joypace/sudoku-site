Finned X-Wing: an x-wing with an extra case.

An X-Wing with an extra case.

The idea

An extra candidate, the fin, adds a case to a two-line fish. If the fin is true, it rules out its peers. If the fin is false, the ordinary fish applies. Remove only notes excluded in both cases.

Every target must see every fin and lie on a fish cover outside its base lines. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Finned X-Wing: example 1

Digit 8: base rows 6, 7; cover columns 3, 5. Every base candidate is included in the highlight: r6c2, r6c3, r6c5, r7c3, r7c5. The fin is at r6c2, in box 4. Each target sees this complete fin set.

Copy the original once for each possible value of the same starting cell:

  1. If r6c2 is 3, the forced placements are r6c5 = 8, r7c3 = 8.
  2. If r6c2 is 8, that placement itself rules out the target notes.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 8 from r4c3.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
