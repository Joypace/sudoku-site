Hidden Triple: three digits reserve three cells.

Three digits reserve three cells.

The idea

Find three missing digits whose possible places in a unit are confined to three cells. Those cells belong to the three digits; remove their other notes.

Check every place for each of the three digits across the entire unit. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Hidden Triple: example 1

In box 5, use cells r4c5, r6c4, r6c6 and digits 1, 3, 4.
  • 1 can appear only at r4c5, r6c6 in this unit.
  • 3 can appear only at r6c4, r6c6 in this unit.
  • 4 can appear only at r4c5, r6c4 in this unit.

Copy the original once for each possible value of the same starting cell:

  1. If r6c6 is 1, the forced placements are r4c5 = 4, r6c4 = 3.
  2. If r6c6 is 3, the forced placements are r4c5 = 1, r6c4 = 4.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 8 from r6c4.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
