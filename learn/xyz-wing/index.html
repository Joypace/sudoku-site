XYZ-Wing: include the pivot in the shared view.

Include the pivot in the shared view.

The idea

The pivot contains X/Y/Z and sees wings X/Z and Y/Z. One of those three cells must be Z, so remove Z only from cells that see all three.

The extra Z possibility in the pivot changes which cells can lose Z. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

XYZ-Wing: example 1

Pivot r4c5 has 2, 7, 8. Its wings are r4c2 (2, 8); r6c5 (2, 7). Both wings see the pivot. The shared elimination digit is 2.

Copy the original once for each possible value of the same starting cell:

  1. If r4c5 is 2, that placement itself rules out the target notes.
  2. If r4c5 is 7, the forced placements are r6c5 = 2.
  3. If r4c5 is 8, the forced placements are r4c2 = 2.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 2 from r4c4.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
