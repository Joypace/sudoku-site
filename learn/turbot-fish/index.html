Turbot Fish: one of the two ends must be true.

One of the two ends must be true.

The idea

Follow one digit through four candidates. Each of two complete units has exactly two places for the digit. Connect one candidate from each pair through a shared unit. If the first free end is not the digit, its partner is forced, ruling out the connector in the second pair and forcing its free end. Thus at least one free end holds the digit; remove it wherever both ends are visible.

A strong link has exactly two possible places in its complete unit. The connecting weak link only requires two cells that cannot both hold the digit; its unit can contain other candidates. Skyscraper and Two-String Kite are familiar shapes of this same four-candidate chain. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Turbot Fish: example 1

For 1, row 9 has only r9c4 and r9c1; box 5 has only r6c4 and r4c5.

The connectors r9c4 and r6c4 share column 4, so they cannot both be 1. If r9c1 is not 1, r9c4 must be 1, which forces r4c5 to be 1. Therefore r9c1 or r4c5 holds 1.

Copy the original once for each possible value of the same starting cell:

  1. If r9c1 is 1, that placement itself rules out the target notes.
  2. If r9c1 is 7, the forced placements are r9c4 = 1, r4c5 = 1.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 1 from r4c1.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
