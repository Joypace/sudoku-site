Remote Pairs: carry a two-note choice along a chain.

Carry a two-note choice along a chain.

The idea

Link an even number of cells with the same two notes, each seeing the next. Their values alternate, so the ends take opposite digits. A cell seeing both ends loses either of those digits that is present.

Use the complete linked path. A disconnected collection of matching pairs does not prove an elimination. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Remote Pairs: example 1

Follow r1c6 → r8c6 → r8c8 → r9c7. Every cell contains exactly 8/9; consecutive cells see each other. The first and last cells take opposite values.

Copy the original once for each possible value of the same starting cell:

  1. If r1c6 is 8, the forced placements are r8c6 = 9, r8c8 = 8, r9c7 = 9.
  2. If r1c6 is 9, the forced placements are r8c6 = 8, r8c8 = 9, r9c7 = 8.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 8 from r1c7.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
