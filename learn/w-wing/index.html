W-Wing: matching pairs connected by a strong link.

Matching pairs connected by a strong link.

The idea

Two nonseeing cells share the same two candidates. A strong link on one digit connects them. At least one pair cell takes the other digit; remove it where both pair cells are visible.

A strong link means exactly two possible places for that digit in a complete row, column or box. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

W-Wing: example 1

r1c2, r8c8 each have only 2/8. In box 3, 2 has exactly two places: r1c9, r2c8. Each end of that link sees its corresponding pair cell. Eliminate 8 only where both pair cells are visible.

Copy the original once for each possible value of the same starting cell:

  1. If r8c8 is 2, the forced placements are r1c9 = 2, r1c2 = 8.
  2. If r8c8 is 8, that placement itself rules out the target notes.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 8 from r8c2.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
