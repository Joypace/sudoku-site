Simple Coloring: opposite possibilities through strong links.

Opposite possibilities through strong links.

The idea

Exactly two places for a digit in a unit form a strong link. Following connected links produces two alternating groups. A target seeing a member of each group cannot contain the digit.

These examples demonstrate Color Trap. A color is a logical alternative, not a claim that every linked cell is simultaneously true. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Simple Coloring: example 1

Digit 3 is linked through r1c6, r3c4, r3c8, r7c2, r7c4, r8c6. The two alternatives are group A (r1c6, r3c8, r7c4) and group B (r3c4, r7c2, r8c6). Each listed edge is a complete two-place unit: r1c6, r3c4; r1c6, r8c6; r3c4, r3c8; r3c4, r7c4; r7c2, r7c4; r7c4, r8c6. A target sees at least one member of each group.

Copy the original once for each possible value of the same starting cell:

  1. If r8c6 is 3, the forced placements are r3c4 = 3, r7c2 = 3.
  2. If r8c6 is 7, the forced placements are r1c6 = 3, r3c8 = 3, r7c4 = 3.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 3 from r8c8.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
