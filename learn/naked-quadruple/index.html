Naked Quadruple: four cells reserve four digits.

Four cells reserve four digits.

The idea

In one row, column or box, four cells whose combined notes contain exactly four digits reserve those digits. Remove those digits from the unit’s other cells.

Each member can have two, three or four notes. Check the whole set, not just four convenient cells. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Naked Quadruple: example 1

In box 9, the four cells are r7c9, r8c7, r8c8, r9c9 and the four reserved digits are 2, 5, 6, 7.

Copy the original once for each possible value of the same starting cell:

  1. If r8c8 is 2, the forced placements are r8c7 = 6, r7c9 = 5, r9c9 = 7.
  2. If r8c8 is 6, the forced placements are r8c7 = 5, r7c9 = 7, r9c9 = 2.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 6 from r7c8.
  • Remove 7 from r7c8.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
