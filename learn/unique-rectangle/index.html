Unique Rectangle Type 1: protect the unique solution.

Two pair guesses, one swappable rectangle.

The idea

In a puzzle known to have one solution, find four originally empty cells in exactly two rows, two columns and two boxes. Three corners have the same two candidates. The fourth—the roof—also has an extra candidate. Either pair value in the roof would force an exchangeable four-cell pattern. The roof must use an extra value.

Uniqueness is a required premise. Every example here is independently verified to have one solution and starts at Dilemma with zero forced singles. The animations show an actual uniqueness warning, distinct from ordinary conflicts or missing choices. r2c1 means row 2, column 1; boxes run left to right, top to bottom. Each link opens the exact starting clues; display settings may differ.

Example 1 of 3

Unique Rectangle Type 1: example 1

The four originally empty corners are r1c7, r1c9, r4c7, r4c9. They occupy rows 1/4, columns 7/9, and exactly boxes 3/6.

  • r1c9 has only 1/6.
  • r4c7 has only 1/6.
  • r4c9 has only 1/6.
  • The roof, r1c7, has 1, 6, 7. It is the corner with an extra candidate.

Copy the original once for each roof candidate. Only the first fill on each copy is a guess; every later corner fill is forced.

  1. Try 1 at r1c7. The forced corner fills are r1c9 = 6, r4c7 = 6, r4c9 = 1. The app then shows the four-cell uniqueness warning. If this trial had a completion, exchanging 1 and 6 in those four cells would preserve all givens and every row, column and box constraint, creating a different completion. That conflicts with the verified single solution, so this roof value is ruled out.
  2. Try 6 at r1c7. The forced corner fills are r1c9 = 1, r4c7 = 1, r4c9 = 6. The app then shows the four-cell uniqueness warning. If this trial had a completion, exchanging 1 and 6 in those four cells would preserve all givens and every row, column and box constraint, creating a different completion. That conflicts with the verified single solution, so this roof value is ruled out.
  3. Try 7 at r1c7. This extra-candidate trial remains an ordinary valid partial board. It is shown as a hypothesis, not as a completed solution.
The conclusion

Remove 1 and 6 from r1c7. The extra value 7 remains.

The rejected copies carry a uniqueness warning. This is not an assertion that the original puzzle has two solutions.
