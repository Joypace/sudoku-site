Two-String Kite: a row and column tied in one box.

A row and column tied in one box.

The idea

A row and a column each offer exactly two places for a digit. Connect one end of each link inside a box. At least one free end contains the digit, excluding it where both free ends are visible.

The connecting cells must be distinct cells sharing a box; the free ends provide the elimination. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Two-String Kite: example 1

For digit 6, the complete strong links are r1c2, r1c5 and r3c3, r4c3. The connecting cells r1c2 and r3c3 share a box. The free ends are r1c5, r4c3; at least one must contain 6.

Copy the original once for each possible value of the same starting cell:

  1. If r3c3 is 2, the forced placements are r4c3 = 6.
  2. If r3c3 is 6, the forced placements are r1c5 = 6.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 6 from r4c5.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
