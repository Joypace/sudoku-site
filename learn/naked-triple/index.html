Naked Triple: three cells reserve three digits.

Three cells reserve three digits.

The idea

Find three cells in one unit whose combined candidates contain exactly three digits. Those digits must fill those cells, so remove them from the unit’s other cells.

The cells need not all contain three notes. Two-note cells can be part of a triple. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Naked Triple: example 1

In box 2, use cells r1c4, r2c4, r3c4 and digits 4, 6, 9.
  • r1c4 has only 4, 9.
  • r2c4 has only 6, 9.
  • r3c4 has only 4, 6.

Copy the original once for each possible value of the same starting cell:

  1. If r3c4 is 4, the forced placements are r1c4 = 9, r2c4 = 6.
  2. If r3c4 is 6, the forced placements are r1c4 = 4, r2c4 = 9.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 6 from r2c6.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
