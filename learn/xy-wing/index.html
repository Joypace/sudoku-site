XY-Wing: a two-note pivot connects two wings.

A two-note pivot connects two wings.

The idea

A pivot has candidates X/Y. It sees an X/Z cell and a Y/Z cell. Either pivot choice puts Z in a wing; remove Z from cells that see both wings.

Seeing the pivot alone is not enough. An elimination must see both wings. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

XY-Wing: example 1

Pivot r4c3 has 2, 6. Its wings are r4c5 (2, 7); r6c1 (6, 7). Both wings see the pivot. The shared elimination digit is 7.

Copy the original once for each possible value of the same starting cell:

  1. If r4c3 is 2, the forced placements are r4c5 = 7.
  2. If r4c3 is 6, the forced placements are r6c1 = 7.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 7 from r6c5.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
