Multi-Coloring: two connected groups, one shared conclusion.

Two connected groups, one shared conclusion.

The idea

A strong link has exactly two places for one digit in a complete row, column or box. Follow those links to form two separate groups, each with two alternating options. Type 1 uses a conflict between one option in each group: at least one opposite option must hold. Type 2 rejects an entire option that conflicts with both options in the other group.

The option names below describe linked candidates. The animation’s board colours distinguish the actual trials. Type 1 here derives candidates outside both groups; Type 2 removes every member of its rejected option. Every strong-link component and source unit is shown completely. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Multi-Coloring: example 1

This example uses Type 1 for digit 6. In each group, exactly one of its two options must hold; all cells in that option take the digit.

Group A

These complete units each have exactly two places for 6:

  • Column 5: r3c5, r4c5.
  • A1: r3c5.
  • A2: r4c5.

Group B

These complete units each have exactly two places for 6:

  • Row 2: r2c4, r2c7.
  • B1: r2c4.
  • B2: r2c7.

r3c5 and r2c4 see each other in box 2. Therefore A1 and B1 cannot both hold. A2 or B2 must hold.

  • r4c7 sees r4c5 in A2 and r2c7 in B2. Either possibility rules out 6.

This small four-candidate example is also a Two-String Kite in the Turbot Fish family. It introduces the same logic using the two smallest groups; this is another view of that deduction.

Copy the original once for each possible value of the same starting cell:

  1. If r3c5 is 6, the forced placements are r2c7 = 6.
  2. If r3c5 is 8, the forced placements are r4c5 = 6.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 6 from r4c7.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.

Example 2 of 3

Multi-Coloring: example 2

This example uses Type 2 for digit 1. In each group, exactly one of its two options must hold; all cells in that option take the digit.

Group A

These complete units each have exactly two places for 1:

  • Row 5: r5c2, r5c5.
  • Column 5: r1c5, r5c5.
  • Box 5: r5c5, r6c4.
  • A1: r1c5, r5c2, r6c4.
  • A2: r5c5.

Group B

These complete units each have exactly two places for 1:

  • Row 3: r3c1, r3c8.
  • Column 1: r3c1, r6c1.
  • Box 3: r1c8, r3c8.
  • B1: r1c8, r3c1.
  • B2: r3c8, r6c1.

Suppose A1 held:

  • r1c5 would contain 1, ruling out r1c8 in row 1 and therefore rejecting option B1.
  • r5c2 would contain 1, ruling out r6c1 in box 4 and therefore rejecting option B2.

Group B cannot lose both of its options. So A1 is impossible: remove 1 from every cell in that option. Different members of the same option may make the two conflicts.

Copy the original once for each possible value of the same starting cell:

  1. If r1c8 is 1, the forced placements are r2c4 = 1, r3c1 = 1, r6c3 = 1.
  2. If r1c8 is 2, the forced placements are r3c8 = 1, r6c1 = 1, r5c5 = 1.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 1 from r1c5.
  • Remove 1 from r5c2.
  • Remove 1 from r6c4.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.

Example 3 of 3

Multi-Coloring: example 3

This example uses Type 2 for digit 2. In each group, exactly one of its two options must hold; all cells in that option take the digit.

Group A

These complete units each have exactly two places for 2:

  • Row 7: r7c1, r7c2.
  • Column 1: r6c1, r7c1.
  • Box 7: r7c1, r7c2.
  • A1: r6c1, r7c2.
  • A2: r7c1.

Group B

These complete units each have exactly two places for 2:

  • Row 2: r2c2, r2c4.
  • Row 4: r4c3, r4c4.
  • Column 4: r2c4, r4c4.
  • Column 6: r3c6, r6c6.
  • Box 2: r2c4, r3c6.
  • Box 5: r4c4, r6c6.
  • B1: r2c2, r3c6, r4c4.
  • B2: r2c4, r4c3, r6c6.

Suppose A1 held:

  • r7c2 would contain 2, ruling out r2c2 in column 2 and therefore rejecting option B1.
  • r6c1 would contain 2, ruling out r4c3 in box 4 and therefore rejecting option B2.

Group B cannot lose both of its options. So A1 is impossible: remove 2 from every cell in that option. Different members of the same option may make the two conflicts.

A Finned X-Wing in columns 3, 6 also removes 2 at r6c1. The whole-option Multi-Coloring argument also covers r7c2.

The trial cell has three candidates. All three are tested, even when two different off-digit choices lead to the same chain option.

Copy the original once for each possible value of the same starting cell:

  1. If r4c3 is 2, the forced placements are r2c4 = 2, r3c2 = 2.
  2. If r4c3 is 3, the forced placements are r4c4 = 2, r3c6 = 2, r2c2 = 2, r6c3 = 2.
  3. If r4c3 is 6, the forced placements are r4c4 = 2, r3c6 = 2, r2c2 = 2, r6c3 = 2.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 2 from r6c1.
  • Remove 2 from r7c2.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
