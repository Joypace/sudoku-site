Hidden Quadruple: four digits reserve four cells.

Four digits reserve four cells.

The idea

Find four missing digits whose possible places in a unit are confined to four cells. Those cells belong to those digits; remove every other note from them.

Count all places for every reserved digit in the complete unit. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Hidden Quadruple: example 1

Count each reserved digit across the complete column 6:

  • 1 appears only at r5c6, r9c6.
  • 5 appears only at r2c6, r9c6.
  • 8 appears only at r2c6, r8c6.
  • 9 appears only at r5c6, r8c6.

These four digits have only four cells between them: r2c6, r5c6, r8c6, r9c6. All four cells are needed, so their other notes can be removed.

Copy the original once for each possible value of the same starting cell:

  1. If r8c6 is 8, the forced placements are r5c6 = 9, r9c6 = 1, r2c6 = 5.
  2. If r8c6 is 9, the forced placements are r2c6 = 8, r9c6 = 5, r5c6 = 1.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 2 from r2c6.
  • Remove 7 from r2c6.
  • Remove 2 from r5c6.
  • Remove 2 from r9c6.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
