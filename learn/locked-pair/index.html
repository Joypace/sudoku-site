Locked Pair: one pair reserves two houses.

One pair reserves two houses.

The idea

When two cells in one row or column each have only the same two candidates and also lie in the same box, those digits occupy the pair in both houses. Remove them from the other cells in the line and the box.

Count the full line and full box. An elimination must be outside the pair and share at least one of those houses. These examples show a useful elimination outside the intersection in each house. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Locked Pair: example 1

r8c7 and r8c8 have only 8/9. They share both row 8 and box 9.

One of the pair cells takes 8; the other takes 9. That reserves both digits in the complete row and the complete box.

Copy the original once for each possible value of the same starting cell:

  1. If r8c7 is 8, the forced placements are r8c8 = 9.
  2. If r8c7 is 9, the forced placements are r8c8 = 8.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 9 from r7c8.
  • Remove 9 from r8c4.
  • Remove 8 from r8c6.
  • Remove 8 from r9c7.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
