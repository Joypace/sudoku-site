Sashimi X-Wing: when the fin-free fish becomes forced.

When the fin-free fish becomes forced.

The idea

For one digit, two base rows or columns normally use two crossing covers. A fin lies outside those covers. In these examples, removing the fin leaves just one candidate in its base, starting forced placements instead of leaving an intact X-Wing. A target outside the bases can lose the digit only if it lies on a cover and sees the fin.

These examples use one fin and a 1+2 body. The same four-candidate geometry can also be read as a Skyscraper; these are two descriptions of the same logical mechanism, not independent deductions. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Sashimi X-Wing: example 1

For 9, these are all its places in the two base columns:

  • Column 6: r6c6, r8c6.
  • Column 7: r4c7, r8c7.

The covers are rows 6, 8. The fin is r4c7, in box 6, outside the covers.

If the fin is 9, it directly excludes every target. If not, r8c7 = 9 is forced, then r6c6 = 9. That is the degenerate fin-free case. Both alternatives exclude the same target notes.

Copy the original once for each possible value of the same starting cell:

  1. If r4c7 is 4, the forced placements are r8c7 = 9, r6c6 = 9.
  2. If r4c7 is 9, that placement itself rules out the target notes.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 9 from r6c8.
  • Remove 9 from r6c9.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
