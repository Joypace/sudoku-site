Swordfish: three lines, three crossing lines.

Three lines, three crossing lines.

The idea

For one digit, find three rows whose candidates lie in just three columns. The three rows occupy those columns, excluding the digit elsewhere in them. Rows and columns can swap roles.

Not every intersection of the three base lines and three crossing lines needs to contain the digit. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Swordfish: example 1

Digit 4 is restricted to columns 3, 4, 6 across rows 1, 4, 5.
  • Row 1: r1c4, r1c6.
  • Row 4: r4c3, r4c4.
  • Row 5: r5c3, r5c6.

Copy the original once for each possible value of the same starting cell:

  1. If r5c3 is 4, the forced placements are r1c6 = 4, r4c4 = 4.
  2. If r5c3 is 8, the forced placements are r4c3 = 4, r1c4 = 4, r5c6 = 4.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 4 from r9c3.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
