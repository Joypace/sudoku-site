Skyscraper: compare the two roofs.

Compare the two roofs.

The idea

Two parallel units each have just two places for a digit. Align one place from each unit as a base. At least one unaligned roof must contain the digit; eliminate it where both roofs are visible.

A strong link means exactly two places for a digit in a complete unit: if one is ruled out, the other is forced. Count every candidate in both source units. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Skyscraper: example 1

For digit 9, the complete strong links are r1c1, r4c1 and r1c5, r5c5. The base cells r1c1 and r1c5 share a crossing line. The free ends are r4c1, r5c5; at least one must contain 9.

Copy the original once for each possible value of the same starting cell:

  1. If r5c5 is 4, the forced placements are r1c5 = 9, r4c1 = 9.
  2. If r5c5 is 9, that placement itself rules out the target notes.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 9 from r5c3.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
