Jellyfish: four lines, four crossing lines.

Four lines, four crossing lines.

The idea

For one digit, four base rows restricted to four columns reserve those columns. Remove that digit from the columns outside the four rows. Rows and columns can exchange roles.

Not every intersection needs a candidate. Every base must be considered in full. Every example starts at Dilemma with zero forced singles. Its native highlight shows the complete named premises. Each play link opens exactly the starting clues shown here; display settings may differ. r2c1 means row 2, column 1; boxes run left to right, top to bottom.

Example 1 of 3

Jellyfish: example 1

Digit 7: base rows 1, 2, 4, 5; cover columns 2, 3, 8, 9. Every base candidate is included in the highlight: r1c8, r1c9, r2c2, r2c3, r4c2, r4c9, r5c3, r5c8.

Copy the original once for each possible value of the same starting cell:

  1. If r5c3 is 7, the forced placements are r1c8 = 7, r2c2 = 7, r4c9 = 7.
  2. If r5c3 is 9, the forced placements are r4c2 = 7, r1c9 = 7, r2c3 = 7, r5c8 = 7.

Only the first move on each copy is a guess. Every later fill is forced. These trials exhaust that cell’s candidates; they are not claims that every trial solves the puzzle.

The shared conclusion
  • Remove 7 from r7c2.
  • Remove 7 from r9c3.

Each target was present initially and is excluded in every trial. A mark from only one trial is not a shared conclusion.
